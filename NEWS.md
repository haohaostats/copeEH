# copeEH 1.0.0

* First package version with coherent marginal fitting and prediction.
* Public coefficient, summary and plotting methods.
* Matched piecewise-constant population mortality functions.
* Restricted state times and deterministic economic outcomes.
* Fixed two-arm synthetic dataset with known truth and standalone package tests.
* Truth-comparison graphics and complete clinical and economic error summaries.
* cope_example() loads fixed data; data-generation code is not shipped.
